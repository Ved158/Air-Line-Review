# ✈️ Airline Reviews Dashboard

## 📌 Project Overview

The Airline Reviews Dashboard is an interactive Tableau project designed to analyze customer reviews and satisfaction across various airlines. The dashboard provides insights into passenger experiences by examining multiple service parameters such as overall rating, cabin staff service, seat comfort, food quality, entertainment, value for money, and more.

This project helps identify customer satisfaction trends, compare airline performance, and support data-driven decision-making through interactive visualizations.

---

## 🎯 Objectives

- Analyze airline customer reviews.
- Identify factors influencing passenger satisfaction.
- Compare airline performance across different service categories.
- Create an interactive dashboard for easy exploration of data.
- Present insights using effective data visualization techniques.
